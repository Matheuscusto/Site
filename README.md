# CLCA Site

Site oficial da CLCA - Automações com IA

## 🚀 Sobre o Projeto

Este é o site da CLCA, uma empresa especializada em soluções de automação com inteligência artificial. O site foi desenvolvido em Next.js com foco em performance e experiência do usuário.

## 🛠️ Tecnologias Utilizadas

- **Next.js** - Framework React moderno
- **React** - Biblioteca de UI
- **TypeScript** - Linguagem tipada
- **CSS** - Estilos personalizados

## 📋 Pré-requisitos

- Node.js 16+ instalado
- npm ou yarn

## 🚀 Como Executar

### 1. Clonar o repositório
```bash
git clone https://github.com/Matheuscusto/Site.git
cd Site
```

### 2. Instalar dependências
```bash
npm install
```

### 3. Executar em desenvolvimento
```bash
npm run dev
```

O site estará disponível em `http://localhost:3000`

### 4. Build para produção
```bash
npm run build
npm run start
```
